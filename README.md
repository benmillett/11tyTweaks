# My collection of 11ty tweaks

My blog repo is private, so this is a public-facing collection of the tweaks I've added to my 11ty site.

## Packages I've installed

- `npm install markdown-it` — [eleventyConfig install instructions](https://www.npmjs.com/package/markdown-it])
- `npm i markdown-it-image-figures` — [eleventyConfig install instructions](https://www.npmjs.com/package/markdown-it-image-figures)
- `npm install remove-markdown` – [remove-markdown](https://www.npmjs.com/package/remove-markdown)
- `npm install —save-dev @11ty/eleventy-img` — [eleventyConfig install instructions](https://www.npmjs.com/package/@11ty/eleventy-img)
- `npm install eleventy-plugin-feathericons —save-dev` — [eleventyConfig install instructions](https://www.npmjs.com/package/eleventy-plugin-feathericons)
- `npm i eleventy-plugin-poison` — [eleventyConfig install instructions](https://www.npmjs.com/package/eleventy-plugin-poison)
- `npm install —save @quasibit/eleventy-plugin-sitemap` — [eleventyConfig install instructions](https://www.npmjs.com/package/@quasibit/eleventy-plugin-sitemap)
- `npm install —save-dev eleventy-plugin-robotstxt` — [eleventyConfig install instructions](https://www.npmjs.com/package/eleventy-plugin-robotstxt)
- `npm install @11ty/eleventy-plugin-rss` — [eleventyConfig install instructions](https://www.11ty.dev/docs/plugins/rss/)
- `npm install —save-dev pagefind` — [eleventyConfig install instructions](https://slecache.com/posts/adding-pagefind-search-to-a-static-eleventy-site/)
- `npm install lightningcss --save-dev` – [eleventyConfig install instructions](https://www.11ty.dev/docs/quicktips/inline-css/)
- `npm install @11ty/eleventy-plugin-syntaxhighlight` — [eleventyConfig install instructions](https://www.11ty.dev/docs/plugins/syntaxhighlight/)
